💼 Financial Transaction & Performance Analysis Dashboard

📌 Project Overview

This project focuses on analyzing financial transaction data using Microsoft Excel. The dataset was cleaned and prepared for analysis, followed by the development of an interactive dashboard to monitor financial performance, transaction patterns, regional trends, and credit risk indicators.

The dashboard combines KPI cards, data visualizations, and interactive slicers to help users explore financial metrics and identify meaningful patterns in transaction activity.

🛠️ Tools & Technologies

• Microsoft Excel

• Data Cleaning and Preparation

• Pivot Tables and Pivot Charts

• KPI Development

• Interactive Dashboard Design

• Data Visualization

• Slicers and Interactive Filtering

🔍 Key Activities

• Data Cleaning: Cleaned and prepared the financial transaction dataset to improve data quality and support reliable analysis.

• KPI Development: Created key performance indicators to summarize financial metrics, including net amount, fees collected, total discounts, and average customer credit score.

• Transaction Analysis: Analyzed transaction amounts across different payment methods and examined the distribution of transaction types.

• Regional Performance Analysis: Compared transaction amounts across regions to identify differences in financial activity.

• Credit Risk Analysis: Examined average customer credit scores across different risk levels to understand patterns in the dataset.

• Interactive Dashboard Development: Designed an Excel dashboard with KPI cards, charts, and slicers to enable dynamic filtering by account type, transaction status, category, and branch.

📊 Dashboard Highlights

• Total Net Amount

• Total Fees Collected

• Total Discount

• Average Customer Credit Score

• Total Amount by Payment Method

• Total Amount by Region

• Transaction Type Distribution

• Average Credit Score by Risk Level

• Interactive Slicers for Data Exploration

💡 Business Value

The dashboard provides a consolidated view of financial transaction activity and performance. It enables users to compare payment methods and regional performance, monitor key financial metrics, and explore customer credit score patterns through interactive filtering.

These insights can support financial reporting, performance monitoring, and data-informed decision-making.
